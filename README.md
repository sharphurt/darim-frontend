# Дарим — фронтенд

Клиент общего вишлиста Darim на React, JavaScript и Vite. [Репозиторий Darim](https://github.com/tripples25/darim)

## Локальный запуск

Понадобится Node.js 24 с npm.

```sh
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite. По умолчанию это `http://localhost:5173`.

Для работы с API запустите сервер Darim по инструкции из его репозитория. В режиме разработки Vite проксирует запросы к `/api` и `/auth` на `http://127.0.0.1:5080`.

## Проверки

```sh
npm run lint
npm run build
```

Сборка сохраняется в `dist/`. Команда `npm run preview` запускает её локальный просмотр.

## Вход по коду

Если сервер сообщает `codeLoginEnabled: true`, рядом со входом через Telegram доступен «Войти по коду». Отправьте `/login` боту в личном сообщении и введите код на сайте. Код действует 5 минут и подходит для первого входа. Запрос отправляется на `/auth/code` без переходов между сайтами; после успешного входа обновляется сессия и сохраняется приглашение в компанию. При ошибке форма остаётся открытой для повторной попытки.

`npm test` проверяет запрос входа и обработку неверного кода вместе с остальными тестами.
