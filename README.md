# Дарим — фронтенд

Клиент общего вишлиста Darim на React, JavaScript и Vite. [Репозиторий Darim](https://github.com/tripples25/darim)

Основной развиваемый интерфейс проекта, заменяющий прежний Razor/Blazor. Backend, API и миграции остаются в `darim`. [AGENTS.md](AGENTS.md) связывает правила работы двух репозиториев; локально удобно держать их рядом.

Подготовка перехода основного сайта, проверка сценариев и откат: [ops/react-cutover.md](ops/react-cutover.md). Факт подготовки не означает, что production уже переключён.

## Ограничения текущего MVP

Во фронтенде временно отключены самостоятельное создание компании, ручной ввод приглашения, управление ссылками на желания и просмотр гостевых заявок из меню. Эти функции требуют доработки пользовательских сценариев. Действующие ссылки на желания и вход в компанию по полученной ссылке-приглашению поддерживаются. Серверные API для этих функций сохранены.

## Локальный запуск

Понадобится Node.js 24 с npm.

```sh
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite. По умолчанию это `http://localhost:5173`.

Для работы с API запустите сервер Darim по инструкции из его репозитория. В режиме разработки Vite проксирует запросы к `/api` и `/auth` на `http://127.0.0.1:5080`.

## Проверки

```sh
npm run lint
npm test
npm run build
```

Сборка сохраняется в `dist/`. Команда `npm run preview` запускает её локальный просмотр.

## Проверка интерфейса в браузере

`ops/check-react.cjs` проверяет мобильные диалоги, подтверждение завершения распила, уведомления, меню MVP, гостевую заявку по действующей ссылке и Mini App с имитацией API. Нужны установленный Playwright и Edge (либо `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`). Запустите Vite на порту 5178 и `node ops/check-react.cjs`; при необходимости укажите `NODE_PATH` на каталог с Playwright и `DARIM_FRONTEND_URL` на другой локальный адрес.

Проверка использует искусственные данные и не подтверждает живые Telegram-вход, БД или интеграцию Ohmywishes. Изображение проверки по умолчанию сохраняется вне отслеживаемых файлов; можно задать `DARIM_SCREENSHOT`.

## Вход по коду

Если сервер сообщает `codeLoginEnabled: true`, рядом со входом через Telegram доступен «Войти по коду». Отправьте `/login` боту в личном сообщении и введите код на сайте. Код действует 5 минут и подходит для первого входа. Запрос отправляется на `/auth/code` без переходов между сайтами; после успешного входа обновляется сессия и сохраняется приглашение в компанию. При ошибке форма остаётся открытой для повторной попытки.

`npm test` проверяет запрос входа и обработку неверного кода вместе с остальными тестами.
