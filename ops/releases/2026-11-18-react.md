## Рабочая схема и откат

Caddy направляет `/api/*`, `/auth/*`, `/health` на `darim-coolify-app:8080`, остальные страницы — на `darim-react-ui:80`. `/deployment.json` сохраняет штатный статус backend-релиза. Backend продолжает доверять IP Caddy `172.28.45.2`.

Активный маршрут: `/data/coolify/proxy/caddy/dynamic/routes.caddy`. Исходный маршрут и ID старого образа сохранены в `/opt/darim/transition-20261118/`. Предрелизная проверенная копия БД: `/opt/darim/backups/pre-deploy-745094dcd36e30f384ec04bc3f10e8c8d64375b5-59-Pxa8jTta.dump`. Не удалять volumes PostgreSQL и Data Protection keys.

Для отката интерфейса восстановить `routes.before` и перезагрузить Caddy с `/config/caddy/Caddyfile.autosave`. Backend и схему при таком откате не менять. Полный откат API/БД требует отдельного контролируемого шага по [инструкции перехода](../react-cutover.md).
